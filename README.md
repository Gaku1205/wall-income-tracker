# wall-income-tracker

バイトのシフトと時給を入力すると、今月と今年の見込み収入と、自分で選んだ扶養・年収の壁まであと何円かがひと目で分かるページ

- 仕様：[docs/spec.md](docs/spec.md)
- 見た目：[docs/design.md](docs/design.md)

[ai-dev-template](https://github.com/Gaku1205/ai-dev-template) の工場で、1行のメモ（バイトのシフトと時給を入れると、今月と今年の見込み収入と、扶養や年収の壁まであと何円かがひと目で分かるページ（壁の金額は自分で選べる））から作ったサービスです。Issue を書くと、AI が清書・実装・レビュー・マージまで進めます（[docs/pipeline.md](docs/pipeline.md)）。
