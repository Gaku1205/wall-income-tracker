# デザイン仕様

wall-income-tracker の見た目のルール（構図・色・文字・動き・部品・文言）。画面に触る作業では、ここに書かれた物だけを使う。

## 体験の核

シフトを1つ置いた瞬間、画面いっぱいの青い「今年の収入」の面がばねで少し持ち上がり、上に張った1本の光る壁の線との隙間が縮む。同時に巨大な「あと◯◯円」の数字が新しい値へ転がって止まる。

- 見立ては使わない。画面にあるのは「横＝1月〜12月、縦＝累計の金額」の面と、壁の金額の水平線だけ。誰が見ても「線まであとどれだけ」が分かる
- 壁の線は指で上下につかんで動かせる。線が動くと、隙間と数字が一緒に変わる

## 構図

ページは1画面（`100svh`）で完結する。スクロールさせない（スマホの日の列だけ横に流れる）。

### 共通の層（奥から順に）

1. **面（canvas、全画面）**：`position: fixed; inset: 0`。画面の端から端まで描く。白い余白で切らない
   - 横軸：左端が1月1日、右端が12月31日。軸の線・目盛りは描かない
   - 縦軸：下端が0円。上端は「壁の金額 × 1.25」と「12月末の見込み × 1.1」の大きい方
   - 今日までに働いた分の累計＝**確定の面**（`--tide` の塗り、不透明度 1）
   - 今日より後の、入力済みのシフトと見込みの累計＝**見込みの面**（`--tide` の塗り、不透明度 0.38）。確定の面の右に続けて描く
   - 今日の位置に、上端から面の上辺まで、幅1pxの縦の光の線（`--glass-line`）
   - 壁の金額の高さに、画面の左端から右端まで、太さ1.5pxの水平線（`--wall`）。線の上下4pxに `--wall` の不透明度0.25のぼかし（canvas の `shadowBlur: 8`）を付けて「光る継ぎ目」にする。黒い線にしない
   - 面が壁を超えた部分は、壁の線より上だけ `--over` で塗る（超えた所が一目で分かる）
2. **ワードマーク（文字、DOM）**：`WALL` を画面の下端に、文字の下3分の1が画面の外にはみ出す位置で敷く。Bricolage Grotesque 800、`font-size: 42vw`（スマホは `60vw`）、`letter-spacing: -0.06em`、色 `--ink` の不透明度 0.07、`mix-blend-mode: multiply`。左揃えで `left: -0.04em`。青い面の中に溶けて沈んで見える。選択・読み上げの対象外（`aria-hidden`）
3. **文字の板（すりガラス）**：数字と操作の後ろだけ `backdrop-filter: blur(18px) saturate(1.4)`、背景 `--glass`。板の端は `mask-image` のグラデーションで 48px かけて消す（硬い境目を作らない）。枠線・影・角丸は付けない

  - 1行目：`あと`（段3）
  - 2行目：残り金額（段1）＋`円`（段3）。数字と単位は下揃え（ベースラインを合わせる）
  - そこから 40px あけて、`今月` `今年` `時給` の3行。左に呼び名（段4・`--mute`）、右に金額（段2）。呼び名の列は幅 3.5em で固定し、金額の左端を揃える
- **日の列**：画面の下、左の余白から右の余白まで。下端から `clamp(24px, 6vh, 64px)` 上。高さ 120px。すりガラスの板（上端だけマスクで消す）。今月の1日〜末日を等幅の列に割る（列の幅は `(板の幅 - 月の名前の幅) / 日数`、最小 24px）
- **壁の名札**：画面の右端に寄せ、壁の線の高さに置く（右の余白は左と同じ）。選んだ壁は段3・`--wall`、ほかの候補は段4・`--mute` で、それぞれの金額の高さに並べる。名札から線の右端へ、長さ16pxの点線（1px・`--wall`）で指す
- 2560px でも数字の板と日の列は上の幅の式で止まり、面と壁の線だけが端まで伸びる

- 最初の1画面に、残り金額・今月・今年・壁の線・日の列が全部入る（667px の高さで確認）

- 日の列は1列 40px 幅で横に流れる（`overflow-x: auto; scroll-snap-type: x mandatory`）。開いたとき今日の列を中央に置く。スクロールバーは隠す
- 壁の名札は選んだ壁だけを出す。ほかの候補は名札を押すと開く選び方（下の「部品」）で出す
- 横にはみ出さない（`overflow-x: hidden` を `body` に。日の列の中だけ流れる）

## 色

灰色は `--tide`（青）の方へ少し寄せる。真っ黒・真っ白は使わない。

| 名前 | 値 | 用途 |
| --- | --- | --- |
| `--sky` | `#E9ECF3` | ページの背景（面より上の空間） |
| `--ink` | `#11131C` | 数字・本文・ワードマーク |
| `--mute` | `#666C82` | 呼び名・単位・候補の壁の名札・未入力の日 |
| `--tide` | `#2B44F0` | 収入の面（確定は不透明、見込みは0.38）。今日の列の印 |
| `--wall` | `#FF5A2E` | 壁の線・選んだ壁の名札・フォーカスの輪 |
| `--over` | `#FF2E6E` | 壁を超えた部分の面と「超過」の数字 |

すりガラス用の派生（新しい色ではなく上の色の透明度違い）

| 名前 | 値 | 用途 |
| --- | --- | --- |
| `--glass` | `rgba(233, 236, 243, 0.52)`（`--sky` の 52%） | 文字の板の背景 |
| `--glass-line` | `rgba(255, 255, 255, 0.7)` | 今日の位置の縦の光の線（canvas の中だけ） |

- 単位（`円`）は数字と同じ色の不透明度 0.55
- 面の上に乗る文字は必ずすりガラスの板の上に置き、`--ink` で読めるようにする

## 文字

Google Fonts から `next/font/google` で読み込む（依存パッケージは増えない）。

| 役 | 書体 | 太さ | 使う所 |
| --- | --- | --- | --- |
| 見出し（数字・ワードマーク） | Bricolage Grotesque | 800（段1）、700（段2） | 金額・`WALL`・壁の名札の金額 |
| 本文 | IBM Plex Sans JP | 500（段3）、400（段4・段5） | 日本語のすべて・時刻 |

大きさの段（5段だけ使う）

| 段 | PC | スマホ | 字間 | 使う所 |
| --- | --- | --- | --- | --- |
| 段1 | `clamp(120px, 12vw, 232px)` | `clamp(72px, 22vw, 104px)` | `-0.045em`、行の高さ 0.9 | 残り金額 |
| 段2 | `40px` | `28px` | `-0.02em` | 今月・今年・時給の金額 |
| 段3 | `20px` | `17px` | `0` | `あと` `円` 選んだ壁の名札 月の名前 |
| 段4 | `14px` | `13px` | `0.02em` | 呼び名・候補の名札・時刻・ボタンの文字 |
| 段5 | `12px` | `12px` | `0.04em` | 日の列の日付の数字・エラー |

- 金額はすべて `font-variant-numeric: tabular-nums` を指定する。そのうえで段1の数字は1文字ずつ `<span>` に分け、各文字を `display: inline-block; width: 0.58em; text-align: center`（`,` だけ `width: 0.28em`）にして、数字が変わっても幅が揺れないようにする
- 段1の数字の右に付く `円` は段3。段1と段3の差（約7倍）で目を引く
- 日本語は 11.5px 未満にしない。`word-break: auto-phrase` を全体に指定する
- 等幅フォントは使わない（時刻も IBM Plex Sans JP の `tabular-nums`）

## 動き

曲線と速さの決まり

- ばね：`stiffness 420, damping 32, mass 1`。requestAnimationFrame で自前に計算する（パッケージは使わない）
- CSS の切り替え：`cubic-bezier(.2, .8, .2, 1)`、0.18秒

| 何が | いつ | どう動く | 時間・曲線 |
| --- | --- | --- | --- |
| 面の上辺（確定・見込みとも） | シフト・時給・壁が変わったとき | 前の形から新しい形へ、12か月ぶんの各点がそれぞれ新しい高さへ流れる。縦軸の上限が変わるときも同じばねで伸び縮みする | ばね |
| 壁の線 | 壁を選ぶ・ドラッグを離したとき | 新しい金額の高さへ流れる。ドラッグ中は指に遅れずに付いてくる（ばねを使わない） | ばね |
| 段1の数字 | 金額が変わったとき | 1桁ずつ縦に転がる（各桁は0〜9の縦の帯を `translateY` で動かし、`overflow: hidden` で1文字だけ見せる）。右の桁ほど 20ms ずつ遅れて止まる | ばね |
| 段2の数字 | 金額が変わったとき | 数値を前の値から新しい値へ数え上げる | 0.4秒、`cubic-bezier(.2, .8, .2, 1)` |
| 日の列の棒 | 押した瞬間 | 押した列が `scale(0.94)` に沈み、離すと戻る。押してから 50ms 以内 | 0.12秒、`cubic-bezier(.2, .8, .2, 1)` |
| 日の列の棒 | シフトが入った・消えたとき | 棒の高さが前の高さから新しい高さへ伸び縮みする | ばね |
| 壁を超えたとき | 面が壁の線を初めて超えた瞬間 | 壁の線が1回だけ太さ 1.5px→3px→1.5px に脈打ち、超えた部分が `--tide` から `--over` へ色が移る | 0.5秒、`cubic-bezier(.2, .8, .2, 1)` |
| 時刻の入れ物 | 日を押したとき | 日の列の板の上に、下から 12px せり上がって現れる（不透明度 0→1） | 0.18秒、`cubic-bezier(.2, .8, .2, 1)` |

**生きている映像（この1か所だけ）**：見込みの面の上辺が、何もしていなくてもごく小さく揺れる。今日の位置で振幅0、右端（12月31日）に向かって振幅が最大 3px まで増える。2つの正弦波（周期 5.2秒 と 8.7秒、横の波長は画面幅の 0.6倍と 0.27倍）を足す。「先ほど決まっていない」ことが手触りで分かる。確定の面と壁の線は揺らさない。

- canvas は `devicePixelRatio`（最大2）で描く。重いときは 0.5倍の解像度で描いて CSS で引き伸ばす
- 開いた直後から揺れている（空の画面で待たせない）。シフトが0件でも、見込みの面は 0円の高さで下端に沿って揺れ、壁の線が光っている
- `prefers-reduced-motion: reduce` では、揺れを止め、ばね・転がる数字・数え上げをすべて止めて、0.12秒の不透明度の切り替えだけにする
- 画面がタブの裏にあるとき（`document.hidden`）は描画を止める

## 部品

ブラウザ標準のボタン・入力欄・スライダーを、枠で囲んで並べない。すべて `<button>` や `<input>` を土台にして見た目を作り直し、キーボード操作とフォーカスの輪は残す。

- **フォーカスの輪（全部品共通）**：`outline: 1.5px solid var(--wall); outline-offset: 3px`。`:focus-visible` のときだけ出す
- **日の列**：1日＝1つの `<button>`。中身は下から伸びる棒（幅は列の 44%、角丸 2px、上だけ）と、その下の日付の数字（段5）
  - 棒の高さはその日の働く時間に比例（8時間で板の高さの 70%）。シフトが無い日は高さ 2px の `--mute` の点
  - 今日より前の日の棒は `--tide`、今日より後は `--tide` の不透明度 0.38（面と同じ約束）
  - 今日の列は日付の数字の下に、幅 4px・高さ 4px の `--tide` の四角を置く
  - 左右の矢印キーで日を移り、Enter で開く。`aria-label` は「10月14日 10:00から15:00」の形
- **時刻の入れ物**（日を押すと出る）：日の列の板のすぐ上に、同じすりガラスの帯として出す（真ん中に浮かぶ札や、画面を暗くする覆いにしない）
  - 中身は1行：`10月14日`（段3）、開始、`–`、終了（段2の数字）、`前と同じ`、`消す`、`閉じる`
  - 開始・終了の時刻は、数字そのものを押せる場所にする。上下にドラッグ（12pxごとに15分）、上下の矢印キーで15分ずつ、数字を押すとその場で打ち込める（`<input inputmode="numeric">` を枠なし・下に1pxの `--mute` の線だけで出す）
  - ボタンは塗りつぶさない。文字（段4・`--ink`）だけで、押すと 0.12秒 `--tide` の不透明度 0.12 の下地がにじむ。`消す` だけは文字が `--over`
  - 開いている間、面の上ではその日の位置に今日の線と同じ形の縦の線（`--tide`）が出る
- **時給**：`時給 1,150円` の数字そのものが入力欄。枠は付けず、押すと数字の下に 1px の `--tide` の線が伸びる（左から 0.18秒）。打ち終わる（Enter かフォーカスが外れる）と面が動く
- **壁の線と名札（壁の選び方）**
  - 壁の線そのものをつかんで上下にドラッグできる（つかめる幅は線の上下 16px）。ドラッグ中は名札が線に付いてきて、金額が1万円単位で変わる。離した所から上下 3% 以内に候補があれば、その候補に吸い付く
  - 名札は `<button>`。押すと、候補の名札が右端に縦に並んで出る（それぞれ自分の金額の高さに。PCは常に出ている）。押した候補に壁の線が流れる
  - 候補の名札は `106万` `123万` `130万` `150万` `160万` と、最後に `自分で`（押すと金額を打ち込める。名札の場所でその場で入力）
  - キーボード：壁の線は `role="slider"`。上下の矢印で1万円、PageUp/PageDown で次の候補へ。`aria-valuetext` は「130万円の壁まで あと312,400円」
- **超えたとき**：段1の上の `あと` が `超過` に変わり、数字と `円` が `--over` になる。数字は超えた金額

## 画面の文言

短く。説明文で補わない。

| 場所 | 文言 |
| --- | --- |
| 段1の上 | `あと`（超えたら `超過`） |
| 金額の単位 | `円` |
| 呼び名 | `今月` `今年` `時給` |
| 壁の名札 | `130万`（選んだ壁）、候補も同じ形。打ち込み用は `自分で` |
| 日の列の月 | `10月` |
| 時刻の入れ物 | `前と同じ` `消す` `閉じる` |
| シフトが0件のとき | 日の列の板の右端に `日を押してシフトを入れる`（段4・`--mute`。1件入れたら消える） |
| 時給が空のとき | 時給の数字の場所に `—`、段2の今月・今年も `—`。面は動かさず 0円で揺れる |
| 保存できなかったとき | 日の列の板の右端に `保存できませんでした`（段5・`--over`）を4秒 |

- 壁の名前（`扶養` `社会保険` など）は名札に書かない。金額だけで示す（長い呼び名を避ける）
- 改行させない。数字の板の行はすべて `white-space: nowrap`

## 避けること

基準の「AIが作った感の正体」のうち、このサービスで特に落ちやすい物。

- **数字を大きく並べたタイル**：今月・今年・残りを同じ大きさの箱3つにしない。残り金額だけを段1にし、ほかは段2の行にする
- **円形のメーター・ドーナツの進み具合**：「壁まで何%」を丸い計器で見せない。横に流れる面と水平の線だけで見せる
- **パネルに区切った定番の家計簿画面**（左に入力フォーム、右にグラフの箱）：面は画面の端まで広げ、文字の後ろだけすりガラスにする
- **小さいタイトル＋説明文**：左上に `wall-income-tracker` や「バイト収入を管理しよう」を置かない。名前は下端の巨大な `WALL` だけ
- **黒に近い背景に蛍光の1色**：背景は明るい `--sky`。壁の色 `--wall` は線と名札だけに使う
- **カレンダーの格子**：7列×5段の月の表を枠線で描かない。日は横1列の棒にする
- **標準の `<input type="time">` や `<select>`** をそのまま出さない
