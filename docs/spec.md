# 仕様書

アプリの「何を・どう動かすか」を書く。AIは作業の前に必ずここを読む。

## 目的

バイトのシフトと時給を入力すると、今月と今年の見込み収入と、自分で選んだ扶養・年収の壁まであと何円かがひと目で分かるページ（元のメモ：バイトのシフトと時給を入れると、今月と今年の見込み収入と、扶養や年収の壁まであと何円かがひと目で分かるページ（壁の金額は自分で選べる））

## 前提

- 使う人：扶養・年収の壁を気にしながらバイトのシフトを入れる学生・パート。1人で、自分のスマホかPCで使う
- 技術：Next.js（App Router）＋TypeScript、テストはVitest
- 保存先はブラウザの `localStorage` だけ（サーバー・アカウントは無し）。シフト・時給・選んだ壁・直前に入れたシフトを保存し、開き直しても残す
- シフトは1日に1つ。開始・終了は同じ日の中（日またぎは扱わない）。時刻は15分単位でなくてもよい（打ち込んだ分単位のまま）
- 収入＝働く時間（終了−開始）×時給。1日ごとに円未満を四捨五入する
- 「今月」は今月の1日〜末日、「今年」は今年の1月1日〜12月31日に入力済みのシフトの合計（今日より前の確定と、今日より後の見込みを両方含む）。過去の年のシフトは今年の計算に入れない
- 時給が空のときは収入をすべて0円として扱う
- 壁の候補は `106万` `123万` `130万` `150万` `160万`（1,060,000円・1,230,000円・1,300,000円・1,500,000円・1,600,000円）。初期値は `130万`。時給の初期値は空
- 残り金額＝壁 − 今年。今年がちょうど壁の金額なら `あと 0円`。壁を1円でも超えたら `超過` で、超えた金額を出す

## 画面

ページは1つ（`/`）。見た目は `docs/design.md` のとおり。このページで出す物とできること：

- **面**：全画面の canvas に、今年の収入の累計を1日ずつ描く（横＝1月1日〜12月31日、縦＝0円〜上限）。今日までが確定の面、今日より後が見込みの面。今日の縦線、壁の水平線、壁を超えた部分の `--over` を描く。縦軸の上限は「壁の金額×1.25」と「今年の合計×1.1」の大きい方。動きは無い静止画（動きは #2）
- **数字の板**：`あと`（超えたら `超過`）、残り金額と `円`、`今月` `今年` `時給` の3行。時給が空なら今月・今年・時給は `—`
- **時給**：数字そのものが入力欄。数字だけを打ち、Enter かフォーカスが外れたときに決まる。空にすると時給が空になる。0以下・数字でない物は空として扱う
- **日の列**：今月の1日〜末日を1日1つのボタンで並べる。棒の高さは働く時間に比例（8時間で70%、それ以上は100%で止める）。左右の矢印キーで日を移る。押すと時刻の入れ物が開く。シフトが0件なら `日を押してシフトを入れる` を出す
- **時刻の入れ物**：日の列の上に出る。開始・終了を数字で打つ（`1000` `10:00` `10` `930` などを受け付け、`10:00` の形に直す）。上下の矢印キーで15分ずつ動く。両方が入っていて終了が開始より後なら保存する。終了が開始以前なら保存せず、`保存できませんでした` を4秒出す
  - `前と同じ`：直前に入れたシフトの開始・終了をその日に入れる。まだ無ければ 10:00–15:00 を入れる
  - `消す`：その日のシフトを消す
  - `閉じる`（または Esc）：入れ物を閉じる
- **壁の選び方**：右端の名札（選んだ壁）を押すと候補が出る（PCは常に出ている）。候補を押すとその金額に壁が移る。壁の線は `role="slider"` で、上下の矢印で1万円ずつ（下限1万円）、PageUp/PageDown で次に大きい・小さい候補へ移る
- **保存できなかったとき**：`localStorage` に書けなかったら `保存できませんでした` を4秒出す
