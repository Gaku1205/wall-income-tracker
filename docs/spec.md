# 仕様書

アプリの「何を・どう動かすか」を書く。AIは作業の前に必ずここを読む。

## 目的

バイトのシフトと時給を入力すると、今月と今年の見込み収入と、自分で選んだ扶養・年収の壁まであと何円かがひと目で分かるページ（元のメモ：バイトのシフトと時給を入れると、今月と今年の見込み収入と、扶養や年収の壁まであと何円かがひと目で分かるページ（壁の金額は自分で選べる））

## 前提

- 使う人：扶養・年収の壁を気にしながらバイトのシフトを入れる学生・パート。1人で、自分のスマホかPCで使う
- 技術：Next.js（App Router）＋TypeScript、テストはVitest
- 保存先はブラウザの `localStorage` だけ（サーバー・アカウントは無し）。シフト・時給・選んだ壁・直前に入れたシフトを保存し、開き直しても残す
- シフトは1日に1つ。開始・終了は同じ日の中（日またぎは扱わない）。時刻は15分単位でなくてもよい（打ち込んだ分単位のまま）
- 収入＝働く時間（終了−開始）×時給。1日ごとに円未満を四捨五入する
- 「今月」は今月の1日〜末日、「今年」は今年の1月1日〜12月31日に入力済みのシフトの合計（今日より前の確定と、今日より後の見込みを両方含む）。過去の年のシフトは今年の計算に入れない
- 時給が空のときは収入をすべて0円として扱う
- 壁の候補は `106万` `123万` `130万` `150万` `160万`（1,060,000円・1,230,000円・1,300,000円・1,500,000円・1,600,000円）。初期値は `130万`。時給の初期値は空
- 残り金額＝壁 − 今年。今年がちょうど壁の金額なら `あと 0円`。壁を1円でも超えたら `超過` で、超えた金額を出す

## 画面

ページは1つ（`/`）。見た目は `docs/design.md` のとおり。このページで出す物とできること：

- **面**：全画面の canvas に、今年の収入の累計を1日ずつ描く（横＝1月1日〜12月31日、縦＝0円〜上限）。今日までが確定の面、今日より後が見込みの面。今日の縦線、壁の水平線、壁を超えた部分の `--over` を描く。縦軸の上限は「壁の金額×1.25」と「今年の合計×1.1」の大きい方。動きは `docs/design.md` の「動き」のとおり（下の「動き」）
- **数字の板**：`あと`（超えたら `超過`）、残り金額と `円`、`今月` `今年` `時給` の3行。時給が空なら今月・今年・時給は `—`
- **時給**：数字そのものが入力欄。数字だけを打ち、Enter かフォーカスが外れたときに決まる。空にすると時給が空になる。0以下・数字でない物は空として扱う
- **日の列**：今月の1日〜末日を1日1つのボタンで並べる。棒の高さは働く時間に比例（8時間で70%、それ以上は100%で止める）。左右の矢印キーで日を移る。押すと時刻の入れ物が開く。シフトが0件なら `日を押してシフトを入れる` を出す
- **時刻の入れ物**：日の列の上に出る。開始・終了を数字で打つ（`1000` `10:00` `10` `930` などを受け付け、`10:00` の形に直す）。上下の矢印キーで15分ずつ動く。数字を上下にドラッグすると 12px ごとに15分動き（上で遅く、下で早く）、離したときに決まる。半端な時刻は、矢印キーと同じく先に15分の区切りへそろえる。動かさずに離すと打ち込める。両方が入っていて終了が開始より後なら保存する。終了が開始以前なら保存せず、`保存できませんでした` を4秒出す
  - `前と同じ`：直前に入れたシフトの開始・終了をその日に入れる。まだ無ければ 10:00–15:00 を入れる
  - `消す`：その日のシフトを消す
  - `閉じる`（または Esc）：入れ物を閉じる
- **壁の選び方**：右端の名札（選んだ壁）を押すと候補が出る（PCは常に出ている）。候補を押すとその金額に壁が移る。壁の線は `role="slider"` で、上下の矢印で1万円ずつ（下限1万円）、PageUp/PageDown で次に大きい・小さい候補へ移る
  - 壁の線は上下 16px の範囲をつかんで上下にドラッグできる（文字の板の上ではつかめない）。ドラッグ中は縦軸の上限を止め、線が指に付いてくる。名札と数字は1万円単位で変わる。離した金額から上下3%（候補の金額の3%）以内に候補があれば、いちばん近い候補に吸い付く。無ければ1万円単位に丸める。1万円〜縦軸の上限の中で動く
  - `自分で`：候補の最後（いちばん小さい候補のすぐ下）に出る。押すとその場で金額を打ち込める。`125` `125万` `103.5` は万円、`1250000` `1,250,000円` は円として読む（1万未満の数は万円）。Enter かフォーカスが外れたら決まる。空・読めない物・1万円未満・Esc は取り消し
- **保存できなかったとき**：`localStorage` に書けなかったら `保存できませんでした` を4秒出す

## 動き

`docs/design.md` の「動き」のとおり。

- ばね（`stiffness 420, damping 32, mass 1`）は requestAnimationFrame で自前に計算する。面は12か月の月末の累計をそれぞればねで動かし、月の中の日はその月の始めと終わりのずれを直線でつないで描く
- 段1の数字は左の桁から 20ms ずつ遅れて動き出す（右の桁ほど遅れて止まる）
- 壁を超えた瞬間は、今年の合計が壁の金額を超えていなかった状態から超えた状態になったとき（開いた直後は数えない）
- 開いた直後の画面は動かさずにそのまま出す
- `prefers-reduced-motion: reduce` では、揺れ・ばね・転がり・数え上げ・脈打ち・棒を押したときの沈み込みを止め、変わった所を 0.12秒で不透明度 0→1 に切り替える。時刻の入れ物も、せり上がらず不透明度だけで現れる
- `document.hidden` の間は面の描画を止める。1コマの平均が 25ms を超える状態が続いたら、面の解像度を 0.5倍にする（開き直すまで戻さない）
